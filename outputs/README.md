# outputs/

This folder contains all figures generated by `notebook/Notebook.ipynb`. Charts are saved automatically when the notebook is run end-to-end.

---

## Folder Structure

```
outputs/
└── charts/          ← PNG figures exported by the notebook
```

## Key Visual Findings

- **`06_model_comparison.png`** — The XGBoost performance ceiling vs. the Tuned LR recommendation is visible here; the gap narrows significantly for Decision Tree.
- **`07_lr_coefficients.png`** — `number_service_outage`, `frustration_index`, and `account_length` are the dominant positive drivers; `discount` is the strongest protective factor.
- **`14_shap_bar.png` / `15_shap_beeswarm.png`** — SHAP confirms the LR coefficient findings; `total_usage` and `account_length` drive the largest SHAP magnitudes across the validation set.
